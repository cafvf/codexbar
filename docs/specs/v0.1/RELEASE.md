# Release 0.1 — Engineering Foundation

Goal: establish the executable engineering rules before the real Codex integration.

## Scope
- Constitution, product specification, ADR mechanism, release/task templates.
- Typed usage domain.
- Usage provider port and mock adapter.
- Core use case, error normalization boundary, view state.
- Unit, contract, integration-lite and architecture tests.

## Exit gate
- Foundation documents exist and are mutually consistent.
- Core tests pass without Codex or GUI installed.
- No real Codex adapter is represented as verified.
